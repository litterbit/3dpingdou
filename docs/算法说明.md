# 拼豆图纸识别算法说明

本文档描述当前版本把"带背景、网格线和中心编号的拼豆图纸"转换成"每格一个逻辑像素的透明 PNG"的完整算法流程与实现细节。代码结构见 [开发文档.md](./开发文档.md)：算法实现按职责拆在 `src/domain/` 各模块（`pixel.ts` 为汇总导出），界面在 `src/ui/`。

## 总览

```
上传图片 → 人工框选 ROI → 自动判断图片类型（格线支持率）
   ├─ 拼豆图纸 → 自动检测网格（投影 → 周期 → 相位候选仲裁）
   │           → 逐格墨迹分析（贯穿线剔除 + inkRatio + 多级 Otsu 阈值）→ 裁剪到有效格外接框
   │           → 人工校准（网格参数 / 逐格占位 / 阈值）→ 环形区域取色
   └─ 像素图   → FFT 频谱估计格子数（失败回退梯度间隔法）→ comb 细化周期
               → 网格线逐条吸附到颜色边界 → 中位数采样 → 背景洪水置空 → 量化
→ 编辑修正 → 导出逻辑尺寸透明 PNG
```

图纸管线的前提：图纸是**正视、规则、每格中心带编号**的拼豆图纸。算法不做透视校正，全局只估计一组 `pitch + phase`。
像素图管线的前提：图像是**放大的像素画截图**（块大小可能不均、带抗锯齿，但网格近似正方）。

## 1. 输入与 ROI

- 图片经 `canvas.drawImage` 解码为 RGBA 位图（`imageToRaster`）。
- 用户拖动框选主图区域（ROI），标题、坐标轴、图例、其他图纸应留在框外。
- `normalizeRoi` 把 ROI 裁剪到图片范围内，并强制最小 8×8 px；不框选则用整张图。

## 2. 网格几何检测（`detectGrid`）

核心观点：**不要试图判断某条结构是不是网格线**。格线、编号文字、色块边缘、虚线……只要在很多单元格里重复，就都是同一个周期的合法证据。检测目标是"单元格晶格（cell lattice）"，X、Y 两个轴先独立计算再联合校正。

### 2.1 梯度投影（`projection`）

- 沿某轴逐位置取另一轴方向的采样点（交叉方向最多约 480 个采样，超出则按步长抽稀）。
- 每个样本取 Sobel 式**亮度梯度**：x 轴信号取 `|L(x+1,y) − L(x−1,y)|`（竖向结构），y 轴反之。
- 每个位置取所有样本的 **0.8 分位数**。
  - 旧版用"暗度中位数"，只保留贯穿全图的格线，把编号文字当污染滤掉；梯度 + 0.8 分位数则把文字、色块边缘也保留为周期证据——网格越淡，编号文字越有价值。0.8 分位数在"只留格线"（中位数）和"被大块色块淹没"（平均值）之间折中。

### 2.2 周期检测：谐波峰列拟合（`findPitch`）

- 先对投影曲线做去趋势（`detrend`，41 px 滑窗均值相减），消除光照不均等低频成分。
- 在去趋势后的残差上做整数 lag 自相关（lag = 8 .. min(64, 长度/4)）。
- 取局部极大峰，三点抛物线插值出亚像素峰位，并过滤掉幅值 < 最强峰 25% 的弱峰（格线↔文字的交叉项会在 p/2 处产生极弱的峰，不过滤会让 p/2 候选靠"峰多"险胜）。
- **谐波拟合**：扫描候选周期 p（0.1 px 步长），统计落在 n×p 附近的峰（容差 max(0.8px, 6%p)），以命中峰的强度和为权重。两个约束：
  - 1p 处必须本身有峰，且其强度 ≥ 最强峰的 40%——防止锁到 p/2，也防止格内"每格重复 3 次的结构"（如多笔画编号产生的 p/3 密集峰列）让 2p/3 这类假周期靠累计权重胜出。
  - 2p 候选会丢掉一半峰（p、3p… 不再是整数倍），证据更多的真周期自然胜出。
- 最后对命中峰做最小二乘 `p = Σ(n·d) / Σ(n²)`。
  - 亚像素精度由多个倍频共同回归得到（每个整数峰 ±0.5 px 的误差被平均），不再需要旧版 ±1.5 px / 0.05 步长的暴力细化。
- **X/Y 联合校正**：拼豆格近似正方形，两边周期相差整数倍（容差 12%）时几乎必有一边锁到倍频，把大的一边除回来。

### 2.3 相位检测：comb 候选 + 格内一致性仲裁（`phaseCandidates` / `cellUniformity`）

- **comb 候选**：以 0.25 px 步长扫描 offset ∈ [0, pitch)，得分 = 梳齿（offset + k·p）处梯度投影的均值。不直接取最大值，而是取**按能量降序的前 5 个局部极大**，外加最强候选的半格平移，作为候选相位集。不惩罚格心——编号文字本身就在格心产生梯度，惩罚它会抵消文字这条证据。
- **为什么不能只信 comb 最大峰**：没有逐格细线的图纸里（只有每 5 格一条的粗线/虚线），编号文字的上/下边缘也是逐格重复的梯度结构，能量可能超过格线，comb 会锁到"文字边缘晶格"，相位偏差可达 0.3–0.4 格（此时文字落到窗口外，后面占位判定会整片失效）。文字中心同样是 p 周期，comb 也可能锁到格心（p/2 歧义）。
- **格内一致性仲裁**：对 X/Y 候选的全部组合分别建格，计算**格内四角颜色方差**（`cellUniformity`，四角 14%–34% 区域、避开格线与编号）。真实格线下每个豆子格内四角同色、方差最小；锁到文字边缘/中心的相位会让格子横跨两个相邻豆子，方差明显变大。取方差最小的组合；方差相差 <15% 视为平局，取 comb 能量高的（保护文字极少、方差没有区分度的图纸）。
- **行列数按格心归属计数**：梯度投影里一条格线有前/后两个边缘峰，comb 锁到的相位可能比格线中心偏 1~2 px；若仍用 `round((ROI 边缘 − 原点) / pitch)`，当原点落在 ROI 边缘内 1~2 px 时会丢掉一整行/列。改为：首格索引 `kMin = ceil(−offset/p − 0.5)`、末格 `kMax = floor((size − offset)/p − 0.5)`，即只统计格心落在 ROI 内的格子，原点随之可以略为负值。

## 3. 占位判定：哪些格子有豆（`analyzeOccupancy`）

### 3.1 单格墨迹比例（`cellInk`）

每格独立计算：

1. **估计底色**：取格子四角 14%–34% 的四个方块区域（避开格线和中心编号），对每个通道取中位数作为该格底色 `base`。
2. **统计墨迹**：在中心 24%–76% 区域内，逐像素算与 `base` 的 RGB 欧氏距离，距离 > `INK_DISTANCE`（= 36）记为"墨迹"。
3. **贯穿线剔除（`lineBands`）**：有些图纸的装饰虚线/实线会穿过格心（虚线周期与格子不对齐），把空格的墨迹比例抬到 0.2–0.4。对窗口内"填充率 ≥0.95 的连续行/列段"按带长分级剔除：≥4 行的满行段多半是文字实心块，不剔除；3 行段要求紧邻行直接为空；≤2 行的细线允许隔一行抗锯齿过渡行，过渡行一并剔除。
4. **线头 veto**：虚线端点落在窗口内时只剩几列宽，够不到整行 95% 填充的剔除条件。对剔除后剩余的墨迹取外接框，若**短边 ≤2px（细）且长宽比 ≥2.2 且矩形填充率 ≥0.55**（细长实心条 = 线头），整格墨迹清零。文字块两个方向都有 4px 以上（即使低对比度文字如红底暗红字，笔画核心也是饱满紧凑块），不受短边条件影响。
5. **水印守卫**：水印是浅灰色（与纸面距离 <60），而编号文字无论底色深浅，笔画核心与底色的距离都 >60。统计强墨迹（距离 > `STRONG_INK_DISTANCE` = 60）占比，低于 `STRONG_MIN`（= 0.02）的格子不是编号，按空白处理（score 清零，不参与 Otsu）。实测有豆格强墨迹占比 ≥0.08，水印格恒为 0。
6. `score = 剩余墨迹像素数 / 剩余区域总像素数`（inkRatio）。

关键点是**比较颜色距离而不是明暗**，所以黑底白字、白底灰字、红底浅字都能识别；白色和浅肤色豆子也不会因为接近背景色而被误删。

### 3.2 自动阈值（`otsuThreshold`）

- 对全部格子的 inkRatio 做**多级 Otsu（3 类，64 桶直方图，枚举两个分割点最大化类间方差），取较低的分割点**。
- 为什么不用二分类 Otsu：墨迹分数常出现三个群体——空白背景（≈0）、有编号的有豆格（0.05–0.4，字号越小分数越低）、图样边缘被"底色污染"的格子（四角采到格外背景色、整格被判墨迹，0.6–1.0）。二分类会把阈值放在文字格与污染格之间（≈0.4），小号文字格全部误判为空；三分割的低阈值正好落在背景与文字之间，只有两类时也退化为正常结果。
- `applyThreshold`：`score > threshold` 判为有豆。

### 3.3 裁剪（`trimAnalysis`）

- 把网格裁剪到有豆格子的外接框（最小/最大有豆行列之间），同时平移几何原点。
- 这一步把 ROI 里留白的多余行/列去掉，行列数就是最终像素图的尺寸。

## 4. 人工校准（校准页）

自动结果叠加在原图上，提供以下修正手段（任何几何变化都会重算 inkRatio 并清空人工翻转）：

- 直接改列数 / 行数（按 ROI 重新均分格宽/格高）、起点 X/Y、格宽/格高。
- **点击对齐交点**：点一个真实格线交叉点，把相位吸附过去（`originX = x − round((x − roi.x) / cellWidth) · cellWidth`），整个无限 lattice 随之确定。
- **逐格翻转占位**：点击 0/1 矩阵中的格子强制改为有豆/空白。
- **阈值滑块**：手动覆盖 Otsu 阈值；分数落在阈值 ±30% 内的格子显示为橙色"不确定"，提示人工检查。
- 占位矩阵预览：绿 = 有豆，棋盘格 = 空白，橙 = 不确定；可显示每格 inkRatio 分数。

## 5. 取色（`sampleCellColor`）

占位确认后逐格采样豆子颜色：

- 去掉外圈 16%（避开格线），再排除中心 28%–72% 区域（避开编号文字）。
- 对剩下的**环形区域**（16%–84% 减 28%–72%）逐通道取中位数。
- 中位数抗噪：少量编号笔画探出中心区、格线阴影等不会污染主色。

## 6. 颜色量化（`quantizeColors`）

拼豆色号很少（通常 ≤10 种），但抗锯齿、印刷、光照会让同一色号在纸上采样出几十上百个相近 RGB。填充颜色时做凝聚式聚类归并：

- 距离用 **CIE Lab**（感知距离），不用 RGB 欧氏距离——后者对暗色过于敏感、对亮色过于迟钝。
- 算法为**平均联动凝聚聚类**：每种唯一采样色初始为一个簇（按出现次数加权），反复合并质心 Lab 距离最近的两个簇，直到簇数 ≤ 上限（默认 10，校准页可调）且最近簇对距离 ≥ 14。
- 归并后每个格子取所属簇的**加权质心**（取整）作为最终颜色，调色板因此只剩少数几个代表色。
- 曾考虑利用"编号字母相同 → 同色"做辅助分组，但这需要识别/匹配文字形状，复杂且脆弱；纯色聚类在当前图纸上已足够（小黑 277 种采样色 → 7 种，且白眼圈、绿耳标等细节颜色均保留）。

## 7. 悬空块偏移粘连（`floatingBlockOffsets` + `renderMatrix`）

像素图用于 3D 打印时，仅靠一个角（对角）与主体相连的色块会断裂脱落。修复发生在**导出渲染层**，不改动逻辑矩阵：

- **连通性按 4-连通（共享边）判定，不分颜色**——打印件物理上是一个整体，异色共边也算相连。
- 最大的连通域视为主体；与主体存在对角相邻（角接触）的其余连通域（可能是多格、多色的一整块），整体获得一个指向主体的 45° 方向 (±1, ±1)。
- 导出时这些格子按 `每格像素 × 每格像素` 绘制实心方块，悬空块的方块额外沿该方向偏移"悬空块偏移"像素（默认 2 px，可调，钳制到 ≤ 每格像素），与主体色块产生小面积重叠——**允许压住异色**，重叠一个小角不影响观感，打印后悬空块即粘在主体上。
- 被偏移的块最后绘制（压在主体之上）；画布四周各留偏移量的内边距，防止边缘块移出画布。
- 只锚定**直接**角接主体的块：与主体完全分离的孤立块（连角都不挨着）保持原样，编辑页会提示数量，需用画笔手动补连。

## 8. 导出（`renderMatrix` + `exportPng`）

- 编辑页可设置"每格像素"N（1–50，默认 10）：每格绘制成 N×N 实心方块，色块边缘锐利、透明区域不被污染。
- 有豆格写入量化后的代表色（alpha = 255），空白格保持全 0（透明）。
- "悬空块偏移"开启时画布四周各加该值的内边距（见上一节）；无偏移时画布恰为 `列数×行数`（每格 1 px）。

## 9. 图片类型判断（`classifyImage`）

依据是**格线支持率**：拼豆图纸有贯穿整个区域的印刷格线，像素截图没有。

1. 对 ROI 先跑一遍 `detectGrid`（它对像素图也能给出一个"看似合理"的晶格，所以不能只看作不成功）。
2. 沿检测出的每条网格线隔 2px 采样，统计"附近有边缘"的采样点占比：亮度梯度 ≥12，且容许 ±2px 的线位偏差（印刷格线常是浅色细线，严格条件会漏）。
3. `confidence ≥ 0.3 且支持率 ≥ 0.35` 判为图纸，否则判为像素图。实测标定：三张图纸 0.54 / 0.58 / 0.66，两张像素图 0.17 / 0.19，间隔很大。

像素图的"格线"大多落在平坦色块内部（支持率低）；即使碰巧压上色块边界，阶梯状边缘也不连续，支持率仍然远低于贯穿的印刷格线。

## 10. 像素图管线（`detectPixelArt`，移植自 perfectPixel noCV2 版）

处理无格线、块大小不均、带抗锯齿的放大像素截图。三步：

1. **格子数估计**（`estimateGridCount`）：ROI 灰度图（>512px 先降采样，格子数是尺度不变量）做**原尺寸** 2D FFT（Bluestein 任意长度变换——零填充到 2 的幂会移位频谱峰，实测让检测完全失效）；`1 - log1p(|F|)` 反相对数谱 → 行列投影 → 高斯平滑 → `detectPeak` 在中心两侧 (0.25c, 0.75c) 窗口找宽峰对，峰距之半即格子数。合理性校验（格边长 4–30px、两向比 ≤1.5）失败则回退**梯度间隔法**（Sobel 投影局部峰间距中位数）。最后 **comb 搜索**在粗估周期 ±40% 内细化（梯度法会漏检只跨几行的短边界，中位数区间因此偏大；comb 直接最大化梳齿压边能量）。
2. **网格线吸附**（`refineGridLines`）：从 ROI 中心向两侧贪心生长，每条线在理论位置 ±25% 格宽内吸附到最强梯度峰；没有峰则保留理论位置。线不要求等距——这是处理"块大小不均"的关键。
3. **采样与置空**：每格去边 15% 后逐通道取**中位数**（抗抗锯齿边缘与浅色底纹）；然后**背景洪水填充**——以四角格颜色的中位数为背景色，从边界 BFS 所有与背景 Lab 距离 <18 的连通格置空（图案内部的白色块不连通边界，得以保留）；裁掉全空边缘行列；最后复用 `quantizeColors` 量化。

产出的 `PixelMatrix` 与图纸管线完全同构，后续编辑、悬空块修复、导出全部复用。校准步手改行列数/几何后用 `samplePixelMatrix` 在均匀几何上直接重采样。

### 像素图模式的额外局限

- **格子数估计有 ±1–2 列误差**（尤其图样贴边、块边缘被裁切时），校准页确认网格后可手改行列数。
- **很小的图（块 <8px、或总格数 <10）FFT 峰检测不稳定**，与 perfectPixel 原版一致；此时靠梯度法 + comb，仍可能偏 1–2 格。
- **背景色依赖"四角连通浅色"先验**：深色背景、或与图案内部颜色相近的背景会被保留下来（可在编辑页用橡皮擦除）。
- **渐变/阴影会被量化成色号**：像素画若带大面积平滑渐变，量化会把它切成几块色斑；调高"颜色上限"可缓解。

## 11. 已知假设与局限

- **只支持正视规则网格**：全局一组 pitch/phase，轻微透视、纸张弯曲、拍摄倾斜会导致远端格子对不齐（只能整格漂移，无法逐格纠正）。
- **依赖中心编号做占位判定**：`INK_DISTANCE = 36` 是固定阈值，且水印守卫要求编号必须有少量笔画核心距离 >60。没有编号的图纸、编号极淡（全部笔画对比度都在 36–60 之间）、或豆子颜色与编号颜色对比极低的格子会漏判（需手动翻转）。
- **水印按"浅灰"先验剔除**：水印守卫假定水印/污渍与纸面的颜色距离 <60。深色水印（如半透明黑字）笔画核心会超过该阈值，仍会被当成编号墨迹。
- **装饰线的形状先验**：贯穿线剔除假定装饰线是"细直横/竖线"（满行带 ≤3 行、或细长实心条）。粗于 ~4 px 且斜穿格子的装饰线可能被当成墨迹（需手动翻转）。
- **多级 Otsu 需要背景类存在**：整张图几乎全有豆或几乎全空白时，自动阈值不可靠，需手动拖阈值。
- **周期候选范围固定**：pitch 限制在 8–64 px，超出范围的图纸会检测失败。1p 基频峰必须 ≥ 最强峰的 40%，若某张图纸的基频峰异常弱（极端情况），会退而锁定倍频，再由 X/Y 联合校正兜底。
- **相位仲裁依赖颜色差异**：格内一致性靠"格子横跨相邻豆子时四角方差变大"。若图样是大片纯单色且编号文字极弱，多个相位同样均匀，此时由 comb 能量兜底，可能锁到文字边缘晶格。
- **颜色量化可能误并相近色号**：两个真实色号若在 Lab 空间距离 < 14（如浅粉与浅橙），会被合并成一色；调高校准页"颜色上限"可缓解，但根本解是人工编辑修正。
- **悬空块偏移只锚定直接角接主体的块**：与主体完全分离（隔空）的孤立块、以及通过另一个悬空块间接相连的"二级"块都不会偏移，面板会报告数量，需手动补连；偏移量在导出像素层面（与每格像素无关），每格像素调得比偏移量小太多时重叠比例会变大。
- `Lumina` 的宿主功能不参与当前流程；像素图管线（第 10 节）移植自 `perfectPixel` 的 noCV2 版。
